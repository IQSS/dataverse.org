# Editing community calls

Edit **community-calls.md** in this folder. The website renders it at `/community-calls`, linked from the Community tab (`/events`). No React or HTML editing is needed.

Use normal Markdown headings, paragraphs, bullet lists and `[link text](https://example.org)` links. Keep a single `# Community Calls` heading, then `##` section headings. Raw HTML is deliberately disabled. Save, review the local preview, and publish through the existing site workflow.

Update **Upcoming calls** with approved dates, timezone, speakers and agenda links. Move completed calls into **Notes and recordings**. Do not present past calls as upcoming. Keep existing notes and recordings, and provide captions/transcripts for new recordings where available.

The imported history comes from the existing Dataverse community-calls page. Dates and descriptions are retained as supplied; verify source corrections (including the source's April 7, 2027 entry) before editing them. This plain Markdown file can also be reused in a future Hugo migration.
